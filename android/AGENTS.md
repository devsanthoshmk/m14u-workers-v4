# Android

- Capacitor sync regenerates `capacitor.settings.gradle` and `app/capacitor.build.gradle` and copies `dist` into APK assets. Change inputs rather than generated outputs. Use JDK 21 for the Capacitor projects. `capacitor.config.ts` refuses `CAPACITOR_DEBUG_URL` when `RELEASE_BUILD=true` or `CAPACITOR_RELEASE=1`. Configure `JIOSAAVN_AUDIO_ORIGIN` via Gradle property or env var in `android/app/build.gradle` (defaults to `https://m14u-jiosaavn.onrender.com`; must be an HTTPS port 443 origin with path `/` and no query, fragment, or userinfo).
- Android bypasses the website catalog setting and sends `catalog=youtube` through the Worker by default, except when `useSaavnFallbackStore` opens F3 JioSaavn fallback mode (`search.ts` routes Android search/suggestions to `searchJioSaavn(..., { allowNative: true })`) or when resolving `jiosaavn:` tracks (`getStreamData.ts` / `PlaybackService` via `JIOSAAVN_AUDIO_ORIGIN`).
- `MainActivity` registers `StreamExtractorPlugin`, `NativePlaybackPlugin`, and `AppUpdater` before bridge creation and attaches `OfflineBridgeWebViewClient` / `OfflineFallbackPolicy`. Main-frame network or HTTP 5xx errors on the configured server origin redirect to `file:///android_asset/public/offline.html` (no Capacitor bridge on the offline shell, no subresource fallback, sanitized same-origin retry, history cleared on recovery). Back navigates WebView history when online or calls `moveTaskToBack(true)` without stopping playback.
- `NativePlaybackPlugin` (`NativePlayback` v2) owns the `MediaController`, visibility-limited state ticker, `getCapabilities()` (`abiVersion: 2`, `sourceRefresh`, `headlessResolver`, `sandboxSupported`, `saavnUnprimed`, `resolverAbi: "androidx-js-1"`), `loadQueue`/`updateQueue` (`generation`, `resolverKey`, optional `source`), and `setResolvedSources()`. `parseQueue` validates `jiosaavn` `resolverKey.trackId` (`extractSaavnRawId`) while permitting `resolverKey.provider == "jiosaavn"` without a pre-resolved `source` (`m14u-resolve://track/<queueId>`). Queue edits preserving the active `queueId` must leave its `MediaItem` and buffer intact; `setResolvedSources` updates `PlaybackSourceRegistry` without replacing `MediaItem`s.
- `PlaybackSourceRegistry` owns thread-safe, session-scoped source resolution keyed by `queueId` + `generation` + `resolverKey`, enforcing HTTPS public-address URL validation, `jiosaavn` raw ID extraction (`[A-Za-z0-9_-]{1,64}`, accepting `jiosaavn:<id>` or `<id>`), allowlisted headers, expiry pruning, bounded batch/entry limits, 1 retry per load, and v2 `m14u-resolve://track/<queueId>` URIs (keeping legacy `m14u-track://youtube/<id>` compatibility).
- `PlaybackService` owns ExoPlayer/MediaSession, sleep timer, and `PlaybackResolvingDataSource` on the loader thread: pre-resolved `source` (clearing `DefaultHttpDataSource` headers per open/close) -> for `jiosaavn`, `resolveJioSaavnAndOpen` opens validated `${JIOSAAVN_AUDIO_ORIGIN}/api/audio/<id>` directly, caches the resolved URL in `PlaybackSourceRegistry` (`DEFAULT_TTL_MS`), and enforces the 1-retry budget without falling through to YouTube resolvers; for YouTube -> `ResolverEngine` (`AndroidX JavaScriptSandbox` on API 26+, bounded `ResolverHttpBroker`) + `ResolverBundleRepository` (`noBackupFilesDir/resolver-v2`, pinned `BuildConfig.RESOLVER_V2_PUBLIC_KEYS` / `BuildConfig.RESOLVER_V2_MANIFEST_URL`, atomic staging, promotion only after `upstream.open()`) -> transitional `StreamExtractorPlugin` (`NewPipe`) and legacy `proxy` fallback.
- Check affected changes on Android (including `:app:test`, `pnpm test:resolver:smoke`, offline cold start/reconnect, backgrounding, screen-off auto-advance, returning to the app, and lock-screen controls). APK build success covers packaging, not device behavior; [`build-apk.yml`](../.github/workflows/build-apk.yml) runs `pnpm test:resolver:smoke` and [`youtubei-sync.yml`](../.github/workflows/youtubei-sync.yml) automates `youtubei.js` sync PRs and v2 bundle signing.
